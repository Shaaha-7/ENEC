# Project Qandeel: jellyfish swarm response simulation

Team Qandeel's entry to the ATRC Advanced Technology Pioneers 2026 ENEC challenge.
It covers managing Blue Blubber jellyfish (*Catostylus mosaicus*) swarms
**after** an early-warning alert, at a coastal seawater intake.

Everything here is a **simulation on stated assumptions**. No site or ENEC data is
used. The outputs demonstrate the concept; they are not predictions for a real plant.

## Run it

```bash
pip install -r requirements.txt
python -m qandeel.run_all                                # figures + results.json in qandeel/outputs/
python -m qandeel.plan_alert --distance 28 --bearing 285 # operator plan for one alert
python -m pytest qandeel/tests -q
```

## What each part does

| File | What it simulates |
|---|---|
| `qandeel/sim/env.py` | Surface drift: semi-diurnal tide, residual current, 3% wind drift, forecast error |
| `qandeel/sim/planning.py` | Monte Carlo arrival window, curtain switch-on time, approach side, release-point choice |
| `qandeel/sim/curtain.py` | Individual jellyfish (swimming 2–10 cm/s) at the breakwater gap, curtain on or off |
| `qandeel/sim/sizing.py` | Compressor air and power, boom throughput, jellyfish mass |
| `qandeel/plan_alert.py` | Text "dashboard" turning an alert into a plan |
| `qandeel/run_all.py` | Runs everything, writes `outputs/fig1`–`fig4` and `results.json` |

## Key assumptions (defaults)

- Coast along y = 0, intake gap at the origin, gap 300 m wide, 8 m deep.
- Tide amplitude 0.30 m/s along-shore; residual 0.08 m/s eastward; wind 6 m/s from the NW.
- Forecast error: ±20% currents, ±30% wind speed, ±20° wind direction, ±1 h tide phase.
- Curtain surface current from Bulson's empirical relation, U0 = 1.46 (g q)^(1/3),
  decaying over two water depths.
- Boom: 30 m mouth, 1 m surface layer, 0.3 m/s tow, 80% retention, 0.1–1 jellyfish per m³.

## Why no machine-learning model

A model trained on data generated by these drift equations could only re-learn the
equations. The planner runs the physics directly and gets its uncertainty from
Monte Carlo repetition. Learning models make sense once real ENEC swarm events exist.
